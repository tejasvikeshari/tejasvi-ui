# My Journey — photo folder

Drop any photos you want to show in the "My Journey" gallery right into
this folder. That's it — no code editing needed.

- Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`
- The gallery finds every image here automatically and displays it,
  newest-looking layout first (masonry grid), with click-to-enlarge.
- The caption shown under each photo is generated from the file name,
  so name your files descriptively, e.g.:
  - `ncc-camp-2025.jpg` → "Ncc Camp 2025"
  - `uhack-finalist-team.jpg` → "Uhack Finalist Team"
  - `sports-fest-kho-kho.jpg` → "Sports Fest Kho Kho"

Good candidates: NCC parades/camps, college fests, internship photos,
hackathon team pictures, sports events, certificates you'd rather show
as a photo, trips, and any other personal or achievement moment.
